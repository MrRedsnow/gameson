# Project workflow

- Always commit and push completed changes for the current task after the relevant checks pass. The user has authorized this workflow; do not ask for separate confirmation for routine commits and normal pushes.
- Commit only changes belonging to the current task. Preserve unrelated existing changes and never stage the entire working tree indiscriminately.
- Use the current branch and its configured upstream unless the task requires another branch. Do not force-push unless explicitly requested.
